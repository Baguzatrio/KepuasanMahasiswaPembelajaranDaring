# Analisis Kepuasan Pembelajaran Daring Menggunakan Naïve Bayes

## Latar Belakang
Kepuasan mahasiswa dalam pembelajaran daring sulit diukur secara objektif
karena melibatkan banyak faktor. Analisis data diperlukan untuk memahami
pola kepuasan mahasiswa berdasarkan hasil kuesioner.

## Dataset
- Sumber: Kuesioner mahasiswa
- Jumlah data: 110 responden
- Jenis data: Data kategorikal dan numerik

## Pengolahan Data
- Data cleaning dan encoding
- Perhitungan probabilitas Naïve Bayes secara manual menggunakan Excel
- Pembagian data latih dan data uji

## Metode Analisis
- Algoritma klasifikasi Naïve Bayes
- Implementasi menggunakan Python di Google Colab

## Evaluasi
- Pengujian model menggunakan data training dan testing
- Evaluasi hasil prediksi untuk melihat konsistensi model

## Kesimpulan & Insight
Hasil analisis menunjukkan bahwa faktor interaksi dan komunikasi dalam
pembelajaran daring memiliki pengaruh signifikan terhadap tingkat kepuasan
mahasiswa. Model Naïve Bayes memberikan hasil yang konsisten antara
perhitungan manual dan implementasi program.
